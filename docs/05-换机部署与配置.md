# 05 换机部署与配置

> 目标：把项目换到另一台电脑也能跑起来，并且**仓库里不出现任何明文口令**。
> 本文所有命令以 Windows PowerShell 为例，Linux/macOS 只需把 `set X=Y` 换成 `export X=Y`。

## 一、需要准备什么

| 依赖 | 版本 | 是否必需 | 说明 |
| --- | --- | --- | --- |
| JDK | 17 | 必需 | 项目 `pom.xml` 指定 Java 17 |
| MySQL | 8.0（兼容 5.7+） | 必需 | 业务数据 |
| Redis | 5.0+ | 必需 | 缓存、抢单池、分布式锁 |
| Maven | 3.9+ | **不必装** | 仓库自带 `backend/mvnw.cmd` 包装器，会自动下载 |
| Node.js | 18+ | 前端开发需要 | 只跑后端可跳过 |

Maven 不用装：`backend` 目录下的 Maven Wrapper 会在首次执行时自动下载 Maven 3.9.9 到 `~/.m2/wrapper`。

## 二、快速开始（4 步）

### 1) 初始化数据库

```powershell
mysql -u root -p < database/schema.sql          # 建库建表（含 DROP DATABASE，会清空）
mysql -u root -p campus_ai_delivery < database/data.sql   # 演示数据
```

### 2) 启动 Redis

```powershell
# 方式 A：使用仓库脚本（默认目录 D:\SE\redis-5.0.14.1，可用 $env:REDIS_HOME 覆盖）
powershell -ExecutionPolicy Bypass -File scripts\start-redis.ps1

# 方式 B：自己启动
redis-server.exe redis.windows.conf
```

### 3) 配置数据库口令（三种方式，任选其一）

**方式 A：环境变量（推荐用于部署）**

```powershell
$env:DB_USERNAME = "root"
$env:DB_PASSWORD = "你的MySQL口令"
```

**方式 B：本地配置文件（推荐用于个人开发）**

```powershell
cd backend\src\main\resources
copy application-local.yml.example application-local.yml
notepad application-local.yml     # 改成自己的口令
```

`application-local.yml` 已在 `.gitignore` 中，不会被提交。

**方式 C：加密存储（推荐用于共享/演示机器，见第四节）**

### 4) 启动后端

```powershell
cd backend
.\mvnw.cmd spring-boot:run "-Dspring-boot.run.profiles=dev,local"
```

启动成功后可访问接口文档：<http://localhost:8080/api/doc.html>

前端：

```powershell
cd frontend
npm install
npm run dev        # http://localhost:5173
```

## 三、全部可配置项

以下**都不需要改代码**，用环境变量或配置文件覆盖即可。

### 后端

| 环境变量 | 默认值 | 说明 |
| --- | --- | --- |
| `SERVER_PORT` | `8080` | 服务端口 |
| `SERVER_CONTEXT_PATH` | `/api` | 接口前缀 |
| `SPRING_PROFILES_ACTIVE` | `dev` | 生效 profile，本地建议 `dev,local` |
| `DB_URL` | `jdbc:mysql://localhost:3306/campus_ai_delivery?...` | 完整 JDBC 串，设置后忽略下面三个 |
| `DB_HOST` / `DB_PORT` / `DB_NAME` | `localhost` / `3306` / `campus_ai_delivery` | 拆开配置连接 |
| `DB_USERNAME` | `root` | 数据库账号 |
| `DB_PASSWORD` | `CHANGE_ME` | 数据库口令，**可写 `ENC(密文)`** |
| `REDIS_HOST` / `REDIS_PORT` | `localhost` / `6379` | Redis 地址 |
| `REDIS_PASSWORD` | 空 | Redis 口令 |
| `REDIS_DATABASE` | `0` | Redis 库号 |
| `JWT_SECRET` | 开发用占位串 | **生产必须改**，≥32 字符 |
| `JWT_EXPIRE_MINUTES` | `720` | Token 有效期 |
| `CORS_ALLOWED_ORIGINS` | `http://localhost:5173,http://127.0.0.1:5173` | 允许的前端来源，逗号分隔 |
| `UPLOAD_LOCAL_PATH` | `./uploads` | 本地上传目录 |
| `LLM_ENABLED` / `LLM_API_URL` / `LLM_API_KEY` / `LLM_MODEL` | 见 `application.yml` | 大模型配置；不配 Key 时 AI 自动降级为关键词检索 |
| `JASYPT_ENCRYPTOR_PASSWORD` | 无 | 解密 `ENC(...)` 的口令，见下节 |

> 数据库/Redis 也可直接用 Spring Boot 官方变量名覆盖，例如 `SPRING_DATASOURCE_URL`、`SPRING_DATA_REDIS_HOST`。

### 前端

| 变量（写在 `.env.*`） | 默认值 | 说明 |
| --- | --- | --- |
| `VITE_APP_TITLE` | 智能 AI 校园外卖平台 | 页面标题 |
| `VITE_API_BASE_URL` | `/api` | 后端地址；同源相对路径由 Vite 代理转发 |
| `VITE_WS_URL` | 空 | 留空则自动按当前访问地址推导 WebSocket 端点 |
| `BACKEND_ORIGIN`（构建/启动时环境变量） | `http://localhost:8080` | Vite 代理工的后端地址 |

前端**同源设计**：默认 `/api` 走 Vite 代理，因此本机用 `localhost`、同事用局域网 IP 访问都能正常工作，不需要为每台机器改地址。前端已开启 `host: true`，别人的机器可通过 `http://<你的IP>:5173` 访问。

## 四、口令加密（Jasypt）

加密解决的是「配置文件里不出现明文」的问题，适合共享仓库、录屏、演示机等场景。

### 1) 设定密钥

密钥**绝不能提交到仓库**，只放在环境变量或密钥管理系统里：

```powershell
$env:JASYPT_ENCRYPTOR_PASSWORD = "自己生成的一串足够长的随机密钥"
```

生成随机密钥的参考方式：

```powershell
-join ((1..40) | ForEach-Object { [char](Get-Random -Minimum 33 -Maximum 126) })
```

### 2) 生成密文

```powershell
cd backend
.\mvnw.cmd -q -DskipTests compile exec:java `
  "-Dexec.mainClass=com.campus.delivery.common.util.ConfigEncryptor" `
  "-Dexec.args=enc 你的MySQL口令"
```

输出形如：

```
明文      : 你的MySQL口令
写入配置  : ENC(u0XmjKjemkSYpI2zcIqVDbBEDtWUvPE81VLrob/6UKBZkXUANMnWkIqsaFsQdFi9)
```

### 3) 写进配置

`application-local.yml`（或任何配置文件的任何值）：

```yaml
spring:
  datasource:
    username: ENC(把密文粘到这里)
    password: ENC(把密文粘到这里)
```

### 4) 启动时必须提供同一个密钥

```powershell
$env:JASYPT_ENCRYPTOR_PASSWORD = "与加密时完全一致的密钥"
.\mvnw.cmd spring-boot:run "-Dspring-boot.run.profiles=dev,local"
```

密钥不对或缺失时会**直接启动失败**（fail-closed），这是有意设计：避免用错密钥后静默连到错误的环境。

也可以用 JVM 参数传入：`-Djasypt.encryptor.password=...`

### 5) 核对密文是否正确

```powershell
.\mvnw.cmd -q -DskipTests exec:java `
  "-Dexec.mainClass=com.campus.delivery.common.util.ConfigEncryptor" `
  "-Dexec.args=dec ENC(你的密文)"
```

## 五、注意区分两种「密码」

| 场景 | 工具 | 是否可逆 | 存储位置 |
| --- | --- | --- | --- |
| 用户登录口令 | `PasswordGenerator`（BCrypt） | 不可逆 | 数据库 `sys_user.password` |
| 配置里的凭据（数据库口令等） | `ConfigEncryptor`（Jasypt） | 可逆 | 配置文件，形如 `ENC(...)` |

登录口令必须用 BCrypt（不可逆），不要用 Jasypt 加密后入库——那样等于把可解密的凭据放在库里。

## 七、常见问题

**Q：启动报 `Access denied for user 'root'@'localhost' (using password: YES)`**
数据库口令不对。检查 `DB_PASSWORD` / `application-local.yml`。注意：口令错误时 Spring Boot 仍会占用 8080 端口，所以「端口起来了」不等于「连库成功」，请以接口或日志为准。

**Q：启动报解密失败（Unable to decrypt / EncryptionOperationNotPossible）**
`JASYPT_ENCRYPTOR_PASSWORD` 与加密时不一致，或加密/解密算法配置不同。算法在 `application.yml` 的 `jasypt.encryptor.*`，加解密必须一致。

**Q：Redis 连不上**
先确认 Redis 在跑：`redis-cli ping` 应返回 `PONG`。默认连 `localhost:6379`，可用 `REDIS_HOST` / `REDIS_PORT` 调整。

**Q：前端能打开但接口 404/跨域**
确认 `VITE_API_BASE_URL` 与后端 `SERVER_CONTEXT_PATH` 一致（默认都是 `/api`）。局域网访问时后端 `CORS_ALLOWED_ORIGINS` 需要加上对方的来源。

**Q：换电脑后 Maven 下载很慢**
第一次构建会下载依赖。可配置国内镜像：在 `~/.m2/settings.xml` 的 `<mirrors>` 中加入阿里云镜像。

**Q：数据库脚本重复执行会怎样**
`schema.sql` 开头是 `DROP DATABASE`，会清空整库。只想重置演示账号口令请用 `database/reset-demo-password.sql`。
