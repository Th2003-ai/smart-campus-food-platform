## 0. 统一约定（写每个页面前先读）

### 0.1 请求与返回结构
- `import { get/post/put/del } from '@/utils/request'`
- **响应拦截器已统一解包**：`await xxxApi()` 拿到的直接是后端 `Result.data`，不要再 `.data.data`。
- 分页接口返回 `PageResult<T> = { total, pageNum, pageSize, list: T[] }`，列表数据取 **`.list`**。
- 不分页接口直接返回数组（如 `listCart()`、`listKnowledge()`）。
- 拦截器已统一弹错误提示，页面 `catch {}` 里**留空 + 注释**即可，不要重复弹错（参考 `Dishes.vue`）。

### 0.2 标准代码骨架（照抄 Dishes.vue 的写法）
```vue
<script setup lang="ts">
import { onMounted, reactive, ref } from 'vue'
import { ElMessage } from 'element-plus'
import { listXxx } from '@/api/xxx'

const list = ref<Xxx[]>([])
const loading = ref(false)
const page = reactive({ pageNum: 1, pageSize: 10, total: 0 })

async function load() {
  loading.value = true
  try {
    const res = await listXxx({ pageNum: page.pageNum, pageSize: page.pageSize })
    list.value = res.list
    page.total = res.total
  } catch {
    // 拦截器已弹提示
  } finally {
    loading.value = false
  }
}
onMounted(load)
</script>
```

### 0.3 状态码字典（和后端保持一致，不要自己臆造）
| 类型 | 取值 |
|---|---|
| 订单状态 `orderStatus` | 0 待接单 / 1 备餐中 / 2 待取餐 / 3 配送中 / 4 已完成 / 5 已取消 / 6 申诉中 |
| 店铺营业 `businessStatus` | 1 营业中 / 0 休息中 |
| 店铺封禁 `banStatus` | 0 正常 / 1 已封禁 |
| 菜品上下架 `status` | 1 上架 / 0 下架 |
| 骑手在线 `workStatus` | 1 接单中 / 0 休息中 |
| 审核状态 `auditStatus` | 0 待审核 / 1 已通过 / 2 已驳回 |
| 支付状态 `payStatus` | 0 未支付 / 1 **已支付** / 2 已退款。⚠️ 后端 `createOrder` 里直接置为已支付并写入 `payTime`，**下单即视为付好**，没有独立支付动作 |
| 配送方式 `deliveryType` | 1 **骑手配送** / 2 **宿舍楼下自取**。⚠️ 后端判断自取用的是 `deliveryType == 2`，别写反 |
| 情感倾向 `sentiment` | 0 差评 / 1 中评 / 2 好评 |

> ⚠️ 本表 2026-10 已按后端实际代码校正：`payStatus` 与 `deliveryType` 的旧描述是错的。

> 建议在 `src/utils/` 下新建 `dict.ts` 统一放这些映射，避免每个页面重复写。

- 路由跳转：`const router = useRouter()`，`router.push('/student/shop/' + id)`
- 取路由参数：`const route = useRoute(); const id = route.params.shopId as string`
- 购物车统一用 `useCartStore`（已写好 `refresh / selectedAmount / selectedCount / shopId`）
- 用户信息用 `useUserStore`

## 一、学生端（11 个空壳，答辩演示主线，优先级最高）

### 1. Home.vue 首页 ★P0
- `onMounted`：
  - `listShops({ pageNum:1, pageSize:10 })` → 取 `.list`
  - `recommend('HOME', 6)` → 个性化推荐（`@/api/ai`）
- 渲染店铺卡片：`logo`、`shopName`、`score`、`monthlySales`、`minPrice`(起送)、`deliveryFee`、`deliveryTime`(分钟)、`businessStatus` 营业/休息角标
- 交互：点店铺 → `/student/shop/:id`；顶部搜索框 → `/student/search?keyword=`
- 推荐位：渲染返回菜品（含 `dishName/price/image`），点 → `/student/dish/:id`
- 注意：`recommend` 返回类型是 `Record<string, unknown>`，**需联调确认真实字段后断言**（菜品列表大概率在 `dishes` 字段）

### 2. Shop.vue 店铺详情 ★P0
- `const shopId = route.params.shopId`
- `getShopDetail(shopId)` 渲染店铺头部（名称、评分、公告 `notice`、起送价、配送费、营业时间 `openTime`）
- 菜品列表：**见缺口【G1】**，暂用 `searchDishes({ shopId, keyword:'', limit:100 })` 兜底
- 每个菜品：图、名、价、月售、`stock`、加购按钮
- 加购：`addToCart({ dishId, quantity:1 })`（`@/api/cart`），成功后刷新购物车徽标
- 点菜品 → `/student/dish/:id`

### 3. DishDetail.vue 菜品详情 ★P0
- `getDishDetail(dishId)`：大图 `image`、`dishName`、`price`、`description`、`tags`（逗号分隔）、`ingredients`、`monthlySales`、`stock`
- 数量步进器（`el-input-number`，上限 `stock`）
- 「加入购物车」`addToCart({ dishId, quantity })`；售罄（`stock===0` 或 `status===0`）禁用

### 4. Cart.vue 购物车 ★P0（最复杂，下单入口）
- `useCartStore.refresh()` 加载（或 `listCart()`）
- 列表：`dishImage`、`dishName`、`price`、数量步进 → `updateQuantity(id, quantity)`；勾选框 → `updateSelected(id, 0/1)`；删除 → `removeCartItem(id)`
- 顶部：**同店约束提示**（`cartStore.shopId`，后端保证一单只能同店）
- 底部结算栏：`cartStore.selectedAmount` 合计、`selectedCount`；清空 → `clearCart()`
- 起送校验：需先 `getMyShop` 不适用（学生端），用当前店铺 `minPrice` 比对（**见缺口【G1】拿店铺信息**）
- 「去结算」→ 收集收货信息 `listAddress()` → 调 `createOrder()`：
  ```ts
  createOrder({ deliveryType, payType, receiver, receiverPhone, address, remark })
  ```
  成功后跳 `/student/orders`，并 `cartStore.refresh()`
- 结算弹窗：收货地址选择、配送方式、支付方式、备注（**支付动作见缺口【G2】**）

### 5. Orders.vue 我的订单 ★P0
- `listMyOrders({ status, pageNum, pageSize })` 分页
- 顶部 `el-tabs` 按状态 0~6 筛选（传 `undefined` 为全部）
- 订单卡片：`orderNo`、`statusDesc`、`totalAmount`、`createTime`、`items` 缩略（`dishName × quantity`）
- 操作：
  - `orderStatus===0`（待接单）显示「取消」→ `cancelOrder(id, reason)`
  - `orderStatus===4`（已完成）显示「评价」→ 弹评价框 `submitReview({ orderId, score, content, anonymous })`
  - 点卡片 → `/student/orders/:id`

### 6. OrderDetail.vue 订单详情 ★P0
- `getOrderDetail(id)` 返回 `OrderVO = { order, items, statusDesc }`
- 渲染：状态时间线、`orderNo`、`receiver/receiverPhone/address`、商品明细（`OrderItem` 列表）、费用明细（`goodsAmount`/`deliveryFee`/`totalAmount`）、取餐码 `pickupCode`
- 操作：待接单取消；已完成评价（同上）；**支付、申诉见缺口【G2/G3】**

### 7. Search.vue 搜索 ★P1
- 搜索框 + 两个 tab：搜店铺 / 搜菜品
- 店铺：`listShops({ keyword })`；菜品：`searchDishes({ keyword, limit })`
- 可选：语义搜索入口 `semanticSearch({ message })`（`@/api/ai`），返回 `dishes`
- 结果点击跳店铺/菜品详情

### 8. AiOrder.vue AI 点餐 ★P1
- 对话式 UI：维护本地消息数组 + `sessionId`
- 发送：`aiOrder({ message, sessionId, shopId, limit })`
  - 返回 `{ sessionId, reply, dishes, conditions, fallback, modelVersion }`
  - **多轮对话把返回的 `sessionId` 带上**；`fallback===true` 时提示"AI 未命中，转普通结果"
- 渲染 `reply` 文本 + `dishes` 菜品卡片（可直接加购 `addToCart`）

### 9. Profile.vue 个人中心 ★P1
- `getProfile()`：`nickname`、`username`、`phone`、`balance`、头像
- 饮食档案表单：`getDietProfile()` 回填，`saveDietProfile()` 保存（`dietGoal/tastePreference/allergyFoods/dislikeFoods/dailyBudget`）
- 收货地址：`listAddress()` 列表 + `addAddress()` + `removeAddress(id)`（`receiver/phone/address/isDefault`）
- 退出登录：`useUserStore().logout()` → 跳 `/login`

### 10. DietReport.vue 饮食分析 ★P2
- 天数切换（7/30）：`dietReport(days)`
- 返回 `Record<string, unknown>`，**字段需联调**，用卡片/图表（ECharts 或 el-progress）展示营养结构、消费统计、忌口命中
- 可结合 `getDietProfile()` 展示档案

### 11. Chat.vue 智能客服 ★P2
- 对话 UI + `sessionId`：`chat({ message, sessionId })`
  - 返回 `{ sessionId, answer, needTicket, fallback, knowledge, modelVersion }`
  - `needTicket===true` 提示"已为您转人工工单"
- 「清空上下文」`clearChatContext(sessionId)`
